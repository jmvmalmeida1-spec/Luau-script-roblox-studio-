Aula 1

🔦 Como fazer uma lanterna

Você vai aprender a criar uma lanterna simples e depois evoluir para versões com botão, bateria, diferentes tipos de luz e efeitos.

1. PointLight

local luz = script.Parent:FindFirstChildOfClass("PointLight") if luz then luz.Enabled = true luz.Brightness = 2 luz.Range = 16 end

2. SpotLight

local luz = script.Parent:FindFirstChildOfClass("SpotLight") if luz then luz.Enabled = true luz.Range = 30 luz.Angle = 45 end

3. Ligar e desligar

local luz = script.Parent:FindFirstChildOfClass("PointLight") local ligada = false local function alternar() ligada = not ligada if luz then luz.Enabled = ligada end end alternar()

4. Lanterna com ProximityPrompt

local prompt = script.Parent:WaitForChild("ProximityPrompt") local luz = script.Parent:FindFirstChildOfClass("PointLight") local ligada = false prompt.Triggered:Connect(function() if not luz then return end ligada = not ligada luz.Enabled = ligada end)

5. Lanterna como Tool

local Tool = script.Parent local luz = Tool:FindFirstChildWhichIsA("PointLight", true) Tool.Activated:Connect(function() if luz then luz.Enabled = not luz.Enabled end end)

6. Sistema de bateria

local Tool = script.Parent local luz = Tool:FindFirstChildWhichIsA("PointLight", true) local bateriaMax = 100 local bateria = bateriaMax local ligada = false local function atualizarLuz() if luz then luz.Enabled = ligada and bateria > 0 end end Tool.Activated:Connect(function() if bateria <= 0 then ligada = false atualizarLuz() return end ligada = not ligada atualizarLuz() end) task.spawn(function() while Tool.Parent do task.wait(1) if ligada and bateria > 0 then bateria -= 1 if bateria <= 0 then bateria = 0 ligada = false atualizarLuz() end end end end)

7. Exercícios

🟢 Exercício 1: crie uma lanterna com PointLight e faça a luz ligar e desligar.
🟡 Exercício 2: faça a lanterna funcionar com ProximityPrompt.
🟠 Exercício 3: transforme a lanterna em Tool e use o clique para alternar a luz.
🔴 Exercício 4: adicione bateria que diminui enquanto a lanterna está ligada.
🟣 Exercício 5: faça a intensidade da luz diminuir quando a bateria estiver acabando.
🏆 Desafio final: crie uma lanterna completa com som ao ligar, som ao desligar, bateria, luz principal, efeito visual e aviso quando a bateria chegar a 10%.

Aula 8 • IA

👾 Inimigos que seguem e causam dano

Vamos criar a base de um inimigo que encontra o jogador mais próximo, persegue e ataca quando chega perto.

1. Estrutura

Inimigo ├── Humanoid ├── HumanoidRootPart ├── Head └── Script

2. Encontrar jogador próximo

local Players = game:GetService("Players") local inimigo = script.Parent local root = inimigo:WaitForChild("HumanoidRootPart") local function jogadorMaisProximo() local melhor = nil local menor = math.huge for _, player in Players:GetPlayers() do local char = player.Character local pr = char and char:FindFirstChild("HumanoidRootPart") local ph = char and char:FindFirstChildOfClass("Humanoid") if pr and ph and ph.Health > 0 then local distancia = (pr.Position - root.Position).Magnitude if distancia < menor then menor = distancia melhor = player end end end return melhor, menor end

3. Seguir

local humanoid = inimigo:WaitForChild("Humanoid") while humanoid.Health > 0 do local player, distancia = jogadorMaisProximo() if player and player.Character then local pr = player.Character:FindFirstChild("HumanoidRootPart") if pr then humanoid:MoveTo(pr.Position) end end task.wait(0.2) end

4. Dar dano com cooldown

local DANO = 10 local DISTANCIA_ATAQUE = 4 local COOLDOWN = 1 local podeAtacar = true local function atacar(player) if not podeAtacar then return end local char = player.Character local h = char and char:FindFirstChildOfClass("Humanoid") if h and h.Health > 0 then podeAtacar = false h:TakeDamage(DANO) task.delay(COOLDOWN, function() podeAtacar = true end) end end

5. Seguir ou atacar

if distancia > DISTANCIA_ATAQUE then humanoid:MoveTo(playerRoot.Position) else atacar(player) end

6. Raio de visão

local RAIO_DE_VISAO = 40 if distancia <= RAIO_DE_VISAO then humanoid:MoveTo(playerRoot.Position) end

7. Mapas com obstáculos

Para inimigos que precisam contornar paredes e corredores, estude PathfindingService. Ele calcula caminhos usando waypoints.

local PathfindingService = game:GetService("PathfindingService") local path = PathfindingService:CreatePath() path:ComputeAsync(root.Position, playerRoot.Position) local waypoints = path:GetWaypoints()

8. Variações de IA

  • Patrulhar quando não houver alvo.
  • Perseguir somente dentro de um raio.
  • Atacar corpo a corpo.
  • Atacar à distância.
  • Fugir com pouca vida.
  • Escolher o jogador mais próximo.
  • Escolher o jogador com menor vida.
  • Usar estados: Patrulhando, Perseguindo, Atacando e Perdendo o alvo.
  • Ter ataques numerados, como os sistemas de habilidades da aula anterior.

9. Inimigo chefe

local ataques = { [1] = {nome="Golpe", dano=15, cooldown=1}, [2] = {nome="Golpe forte", dano=30, cooldown=4}, [3] = {nome="Investida", dano=20, cooldown=6} }

Aula 9 • Interface + Movimento

❤️‍🔥 Barra de vida + barra de stamina + corrida com Shift

Nesta aula você vai montar uma interface com barra de vida e barra de stamina. A stamina diminui enquanto o jogador corre e o sistema de corrida é ativado segurando Shift no PC.

🧠 Como pensar no sistema:
Vida = quanto o personagem pode receber de dano.
Stamina = recurso temporário usado para correr.
Shift pressionado + stamina disponível = correr.
Shift solto ou stamina vazia = parar de correr.
Quando não está correndo, a stamina pode se recuperar.

1. 🖥️ Criar a interface

No StarterGui, crie um ScreenGui. Dentro dele, crie dois Frames: um para a vida e outro para a stamina.

StarterGui └── StatusGui ├── VidaFundo │ └── Vida └── StaminaFundo └── Stamina

Os Frames chamados Vida e Stamina serão as partes que diminuem visualmente.

2. ❤️ Barra de vida

O personagem usa um Humanoid. A propriedade Health representa a vida atual e MaxHealth representa o máximo.

local Players = game:GetService("Players") local player = Players.LocalPlayer local character = player.Character or player.CharacterAdded:Wait() local humanoid = character:WaitForChild("Humanoid") local barra = script.Parent.VidaFundo.Vida local function atualizarVida() local porcentagem = humanoid.Health / humanoid.MaxHealth porcentagem = math.clamp(porcentagem, 0, 1) barra.Size = UDim2.new(porcentagem, 0, 1, 0) end humanoid.HealthChanged:Connect(atualizarVida) atualizarVida()
Por que usar porcentagem?
Se a vida máxima for 100 e a vida atual for 75, a barra fica em 75%. Se a vida máxima mudar para 200, o mesmo sistema continua funcionando.

3. ⚡ Barra de stamina

Agora vamos criar uma variável para controlar a stamina.

local staminaMax = 100 local stamina = staminaMax local function atualizarStamina() local porcentagem = stamina / staminaMax porcentagem = math.clamp(porcentagem, 0, 1) barraStamina.Size = UDim2.new(porcentagem, 0, 1, 0) end

A ideia é sempre transformar o valor atual em uma proporção entre 0 e 1 para controlar o tamanho da barra.

4. 🏃 Ativar corrida com Shift

Para detectar o Shift no PC, usamos UserInputService. Enquanto o Shift estiver pressionado, o personagem pode correr.

local UserInputService = game:GetService("UserInputService") local correndo = false UserInputService.InputBegan:Connect(function(input, processado) if processado then return end if input.KeyCode == Enum.KeyCode.LeftShift then correndo = true end end) UserInputService.InputEnded:Connect(function(input) if input.KeyCode == Enum.KeyCode.LeftShift then correndo = false end end)

5. ⚙️ Alterar a velocidade

O Humanoid.WalkSpeed controla a velocidade de caminhada do personagem.

local VELOCIDADE_NORMAL = 16 local VELOCIDADE_CORRENDO = 24 local function atualizarVelocidade() if correndo and stamina > 0 then humanoid.WalkSpeed = VELOCIDADE_CORRENDO else humanoid.WalkSpeed = VELOCIDADE_NORMAL end end

6. 🔋 Fazer a stamina descer

Enquanto o jogador estiver correndo, a stamina diminui aos poucos.

local DRENO_POR_SEGUNDO = 20 -- Enquanto corre e anda, a stamina diminui. -- Ao chegar a 0, a corrida para. if correndo and humanoid.MoveDirection.Magnitude > 0 and stamina > 0 then stamina -= DRENO_POR_SEGUNDO * 0.1 stamina = math.clamp(stamina, 0, staminaMax) end
⚠️ Detalhe importante: usamos Humanoid.MoveDirection para a stamina não ser drenada apenas porque o Shift está apertado; ela é drenada quando o personagem realmente está se movimentando.

7. 🔄 Recuperar stamina

Quando o jogador não estiver correndo, podemos recuperar stamina gradualmente.

local REGEN_POR_SEGUNDO = 15 -- Quando não está correndo, a stamina se recupera. if not correndo and stamina < staminaMax then stamina += REGEN_POR_SEGUNDO * 0.1 stamina = math.clamp(stamina, 0, staminaMax) end

8. 🧩 Sistema completo — versão para estudar

Agora junte as ideias principais em um único LocalScript. Coloque o script dentro do seu StatusGui e ajuste os nomes dos Frames conforme a sua interface.

local Players = game:GetService("Players") local UserInputService = game:GetService("UserInputService") local player = Players.LocalPlayer local character = player.Character or player.CharacterAdded:Wait() local humanoid = character:WaitForChild("Humanoid") local gui = script.Parent local barraVida = gui.VidaFundo.Vida local barraStamina = gui.StaminaFundo.Stamina local staminaMax = 100 local stamina = staminaMax local VELOCIDADE_NORMAL = 16 local VELOCIDADE_CORRENDO = 24 local DRENO_POR_SEGUNDO = 20 local REGEN_POR_SEGUNDO = 15 local correndo = false local function atualizarVida() local porcentagem = humanoid.Health / humanoid.MaxHealth porcentagem = math.clamp(porcentagem, 0, 1) barraVida.Size = UDim2.new(porcentagem, 0, 1, 0) end local function atualizarStamina() local porcentagem = stamina / staminaMax porcentagem = math.clamp(porcentagem, 0, 1) barraStamina.Size = UDim2.new(porcentagem, 0, 1, 0) end local function atualizarVelocidade() if correndo and stamina > 0 then humanoid.WalkSpeed = VELOCIDADE_CORRENDO else humanoid.WalkSpeed = VELOCIDADE_NORMAL end end UserInputService.InputBegan:Connect(function(input, processado) if processado then return end if input.KeyCode == Enum.KeyCode.LeftShift and stamina > 0 then correndo = true atualizarVelocidade() end end) UserInputService.InputEnded:Connect(function(input) if input.KeyCode == Enum.KeyCode.LeftShift then correndo = false atualizarVelocidade() end end) humanoid.HealthChanged:Connect(atualizarVida) task.spawn(function() while humanoid.Health > 0 do task.wait(0.1) local andando = humanoid.MoveDirection.Magnitude > 0 if correndo and andando and stamina > 0 then stamina -= DRENO_POR_SEGUNDO * 0.1 if stamina <= 0 then stamina = 0 correndo = false atualizarVelocidade() end elseif not correndo then stamina += REGEN_POR_SEGUNDO * 0.1 end stamina = math.clamp(stamina, 0, staminaMax) atualizarStamina() end end) atualizarVida() atualizarStamina() atualizarVelocidade()

9. 🛡️ Onde colocar o sistema?

  • StarterGui: interface das barras.
  • LocalScript: entrada do teclado e atualização visual.
  • Humanoid: vida e velocidade do personagem.
  • UserInputService: detectar Shift.
  • Servidor: validar regras importantes do jogo em experiências multiplayer.
🔐 Multiplayer: a interface pode ser atualizada localmente, mas sistemas competitivos podem precisar de validação no servidor para evitar que um jogador altere a própria stamina ou velocidade de forma indevida.

10. 🔁 Variações do sistema

  • Shift esquerdo: correr segurando LeftShift.
  • Shift direito: usar RightShift.
  • Toggle: apertar Shift uma vez para começar e outra para parar.
  • Stamina mínima: só permitir corrida acima de 10%.
  • Aceleração: aumentar a velocidade gradualmente.
  • Cansaço: reduzir a velocidade quando a stamina estiver baixa.
  • Regeneração atrasada: esperar alguns segundos antes de recuperar stamina.
  • Celular: trocar o Shift por um botão na tela.
  • Controle: usar um botão do gamepad.
  • Barra numérica: mostrar também “75 / 100”.
  • Barra de escudo: adicionar uma terceira barra para proteção.

🧊 Blender → Roblox Studio

Objetivo: levar um modelo já pintado/texturizado do Blender para o Roblox Studio e depois transformá-lo em um objeto do seu jogo.

1. 🧱 Preparar o modelo

  1. Modele o objeto no Blender.
  2. Confira escala e orientação.
  3. Faça UV Unwrap se usar textura de imagem.
  4. Organize os objetos e nomes.

2. 🎨 Pintar ou texturizar

  • Use Texture Paint para pintar diretamente.
  • Ou use uma imagem como textura do material.
  • Confira o UV e o material antes de exportar.

3. 📦 Exportar

Use um formato compatível com o fluxo de importação 3D do Roblox Studio, como FBX ou OBJ quando apropriado. Mantenha as texturas organizadas para poder configurá-las se necessário.

4. 🏗️ Importar

  1. Abra o Roblox Studio.
  2. Abra o importador de modelos 3D.
  3. Selecione o arquivo exportado.
  4. Confira escala, orientação, materiais e texturas.
  5. Finalize e coloque o modelo no mapa.

5. 🖼️ Se a textura não aparecer

  • Confira o UV.
  • Confira se a imagem está disponível.
  • Confira o material e a textura.
  • Revise a configuração da aparência no Studio.

🧪 Exercícios

🟢 Exercício 1 — Primeiro modelo

Crie uma caixa no Blender, dê uma cor/material, exporte e importe no Roblox Studio.

Objetivo: completar o caminho Blender → Studio.

🟡 Exercício 2 — Textura

Faça UV Unwrap, crie uma textura, aplique ao modelo, exporte e confira se ela aparece no Studio.

Objetivo: entender UV + textura + material.

🟠 Exercício 3 — Espada

Modele uma espada com lâmina, guarda e cabo. Use materiais diferentes e importe no Studio.

Desafio: transformar a espada em uma Tool.

🔴 Exercício 4 — Consertando erros

Teste escala, orientação e textura. Descubra qual configuração precisa ser corrigida quando o modelo chegar diferente do esperado.

🟣 Exercício 5 — Mini projeto

Crie um baú, poção, pedra, porta ou item mágico no Blender, pinte/texturize, importe e coloque no seu mapa.

🏆 Desafio final

Crie um modelo no Blender → pinte → exporte → importe → coloque no mapa → faça um script para ele interagir com o jogador.

🧠 Para memorizar

Modelar → UV → Pintar/Texturizar → Material → Exportar → Importar → Conferir → Testar.

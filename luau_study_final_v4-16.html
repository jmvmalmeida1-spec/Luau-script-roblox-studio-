Aula 1

🔦 Como fazer uma lanterna

Você vai aprender a criar uma lanterna simples e depois evoluir para versões com botão, bateria, diferentes tipos de luz e efeitos.

1. PointLight

local luz = script.Parent:FindFirstChildOfClass("PointLight") if luz then luz.Enabled = true luz.Brightness = 2 luz.Range = 16 end

2. SpotLight

local luz = script.Parent:FindFirstChildOfClass("SpotLight") if luz then luz.Enabled = true luz.Range = 30 luz.Angle = 45 end

3. Ligar e desligar

local luz = script.Parent:FindFirstChildOfClass("PointLight") local ligada = false local function alternar() ligada = not ligada if luz then luz.Enabled = ligada end end alternar()

4. Lanterna com ProximityPrompt

local prompt = script.Parent:WaitForChild("ProximityPrompt") local luz = script.Parent:FindFirstChildOfClass("PointLight") local ligada = false prompt.Triggered:Connect(function() ligada = not ligada luz.Enabled = ligada end)

5. Lanterna como Tool

local Tool = script.Parent local luz = Tool:FindFirstChildWhichIsA("PointLight", true) Tool.Activated:Connect(function() if luz then luz.Enabled = not luz.Enabled end end)

6. Sistema de bateria

local bateria = 100 local ligada = false while true do task.wait(1) if ligada and bateria > 0 then bateria -= 1 end if bateria <= 0 then bateria = 0 ligada = false end end

7. Exercícios

🟢 Exercício 1: crie uma lanterna com PointLight e faça a luz ligar e desligar.
🟡 Exercício 2: faça a lanterna funcionar com ProximityPrompt.
🟠 Exercício 3: transforme a lanterna em Tool e use o clique para alternar a luz.
🔴 Exercício 4: adicione bateria que diminui enquanto a lanterna está ligada.
🟣 Exercício 5: faça a intensidade da luz diminuir quando a bateria estiver acabando.
🏆 Desafio final: crie uma lanterna completa com som ao ligar, som ao desligar, bateria, luz principal, efeito visual e aviso quando a bateria chegar a 10%.
Aula 2

🚪 Portas

Uma porta pode ser ativada de várias formas.

Touched

script.Parent.Touched:Connect(function(hit) local humanoid = hit.Parent and hit.Parent:FindFirstChild("Humanoid") if humanoid then print("Porta ativada") end end)

ProximityPrompt

local prompt = script.Parent:WaitForChild("ProximityPrompt") prompt.Triggered:Connect(function(player) print(player.Name .. " abriu a porta") end)

TweenService

local TweenService = game:GetService("TweenService") local porta = script.Parent local info = TweenInfo.new(0.8) local destino = {CFrame = porta.CFrame * CFrame.Angles(0, math.rad(90), 0)} local tween = TweenService:Create(porta, info, destino) tween:Play()
🧠 Desafio: faça uma porta que abre com E e fecha automaticamente.
Aula 3

✨ Efeitos

ParticleEmitter

local p = script.Parent:WaitForChild("ParticleEmitter") p.Enabled = true p:Emit(25)

Trail, Beam e Highlight

script.Parent.Trail.Enabled = true script.Parent.Beam.Enabled = true script.Parent.Highlight.Enabled = true

Combinar efeitos

local luz = script.Parent:FindFirstChildOfClass("PointLight") local p = script.Parent:FindFirstChildOfClass("ParticleEmitter") local som = script.Parent:FindFirstChildOfClass("Sound") if luz then luz.Enabled = true end if p then p:Emit(30) end if som then som:Play() end
🧠 Desafio: crie uma área mágica com partículas, luz e som.
Aula 4

⚔️ Combate

Tool

local Tool = script.Parent Tool.Activated:Connect(function() print("Ataque iniciado") end)

local origem = workspace.CurrentCamera.CFrame.Position local direcao = workspace.CurrentCamera.CFrame.LookVector * 50 local resultado = workspace:Raycast(origem, direcao) if resultado then print("Acertou:", resultado.Instance:GetFullName()) end

local pronto = true local function atacar() if not pronto then return end pronto = false print("Ataque!") task.wait(0.7) pronto = true end

Tabela numerada

local habilidades = { [1] = function() print("Bola de fogo") end, [2] = function() print("Escudo") end, [3] = function() print("Investida") end } habilidades[1]()

Dados da habilidade

local habilidades = { [1] = {nome="Bola de fogo", dano=25, cooldown=3}, [2] = {nome="Cura", custo=20, cooldown=5} }

Teclas 1–4

local UserInputService = game:GetService("UserInputService") local teclas = { [Enum.KeyCode.One] = 1, [Enum.KeyCode.Two] = 2, [Enum.KeyCode.Three] = 3, [Enum.KeyCode.Four] = 4 } UserInputService.InputBegan:Connect(function(input, processado) if processado then return end local numero = teclas[input.KeyCode] if numero then print("Habilidade:", numero) end end)

Aula 7

🗡️ Troca de armas

O jogador pode estar sem arma ou usando uma espada, e os mesmos números podem representar habilidades diferentes.

Loadouts

local loadouts = { Nenhuma = { [1]="Soco", [2]="Esquiva", [3]="Cura", [4]="Defesa" }, Espada = { [1]="Corte", [2]="Corte Forte", [3]="Investida", [4]="Giro" } } local armaAtual = "Nenhuma" print(loadouts[armaAtual][1])

Troca

local function trocarArma(nome) if loadouts[nome] then armaAtual = nome end end trocarArma("Espada")

Obter habilidade pelo número

local function obterHabilidade(numero) local conjunto = loadouts[armaAtual] return conjunto and conjunto[numero] end print(obterHabilidade(1))

Aula 8 • IA

👾 Inimigos que seguem e causam dano

Vamos criar a base de um inimigo que encontra o jogador mais próximo, persegue e ataca quando chega perto.

1. Estrutura

Inimigo ├── Humanoid ├── HumanoidRootPart ├── Head └── Script

2. Encontrar jogador próximo

local Players = game:GetService("Players") local inimigo = script.Parent local root = inimigo:WaitForChild("HumanoidRootPart") local function jogadorMaisProximo() local melhor = nil local menor = math.huge for _, player in Players:GetPlayers() do local char = player.Character local pr = char and char:FindFirstChild("HumanoidRootPart") local ph = char and char:FindFirstChildOfClass("Humanoid") if pr and ph and ph.Health > 0 then local distancia = (pr.Position - root.Position).Magnitude if distancia < menor then menor = distancia melhor = player end end end return melhor, menor end

3. Seguir

local humanoid = inimigo:WaitForChild("Humanoid") while humanoid.Health > 0 do local player, distancia = jogadorMaisProximo() if player and player.Character then local pr = player.Character:FindFirstChild("HumanoidRootPart") if pr then humanoid:MoveTo(pr.Position) end end task.wait(0.2) end

4. Dar dano com cooldown

local DANO = 10 local DISTANCIA_ATAQUE = 4 local COOLDOWN = 1 local podeAtacar = true local function atacar(player) if not podeAtacar then return end local char = player.Character local h = char and char:FindFirstChildOfClass("Humanoid") if h and h.Health > 0 then podeAtacar = false h:TakeDamage(DANO) task.delay(COOLDOWN, function() podeAtacar = true end) end end

5. Seguir ou atacar

if distancia > DISTANCIA_ATAQUE then humanoid:MoveTo(playerRoot.Position) else atacar(player) end

6. Raio de visão

local RAIO_DE_VISAO = 40 if distancia <= RAIO_DE_VISAO then humanoid:MoveTo(playerRoot.Position) end

7. Mapas com obstáculos

Para inimigos que precisam contornar paredes e corredores, estude PathfindingService. Ele calcula caminhos usando waypoints.

local PathfindingService = game:GetService("PathfindingService") local path = PathfindingService:CreatePath() path:ComputeAsync(root.Position, playerRoot.Position) local waypoints = path:GetWaypoints()

8. Variações de IA

  • Patrulhar quando não houver alvo.
  • Perseguir somente dentro de um raio.
  • Atacar corpo a corpo.
  • Atacar à distância.
  • Fugir com pouca vida.
  • Escolher o jogador mais próximo.
  • Escolher o jogador com menor vida.
  • Usar estados: Patrulhando, Perseguindo, Atacando e Perdendo o alvo.
  • Ter ataques numerados, como os sistemas de habilidades da aula anterior.

9. Inimigo chefe

local ataques = { [1] = {nome="Golpe", dano=15, cooldown=1}, [2] = {nome="Golpe forte", dano=30, cooldown=4}, [3] = {nome="Investida", dano=20, cooldown=6} }
🛡️ Multiplayer: a aplicação de dano e as decisões importantes devem ser validadas no servidor. O cliente não deve ser a autoridade sobre quanto dano um inimigo causou.
🏆 Desafio final: crie um inimigo que patrulha, detecta o jogador, persegue usando caminho, ataca com cooldown, toca animação e som e possui três ataques diferentes.

🧊 Blender → Roblox Studio

Objetivo: levar um modelo já pintado/texturizado do Blender para o Roblox Studio e depois transformá-lo em um objeto do seu jogo.

1. 🧱 Preparar o modelo

  1. Modele o objeto no Blender.
  2. Confira escala e orientação.
  3. Faça UV Unwrap se usar textura de imagem.
  4. Organize os objetos e nomes.

2. 🎨 Pintar ou texturizar

  • Use Texture Paint para pintar diretamente.
  • Ou use uma imagem como textura do material.
  • Confira o UV e o material antes de exportar.

3. 📦 Exportar

Use um formato compatível com o fluxo de importação 3D do Roblox Studio, como FBX ou OBJ quando apropriado. Mantenha as texturas organizadas para poder configurá-las se necessário.

4. 🏗️ Importar

  1. Abra o Roblox Studio.
  2. Abra o importador de modelos 3D.
  3. Selecione o arquivo exportado.
  4. Confira escala, orientação, materiais e texturas.
  5. Finalize e coloque o modelo no mapa.

5. 🖼️ Se a textura não aparecer

  • Confira o UV.
  • Confira se a imagem está disponível.
  • Confira o material e a textura.
  • Revise a configuração da aparência no Studio.

🧪 Exercícios

🟢 Exercício 1 — Primeiro modelo

Crie uma caixa no Blender, dê uma cor/material, exporte e importe no Roblox Studio.

Objetivo: completar o caminho Blender → Studio.

🟡 Exercício 2 — Textura

Faça UV Unwrap, crie uma textura, aplique ao modelo, exporte e confira se ela aparece no Studio.

Objetivo: entender UV + textura + material.

🟠 Exercício 3 — Espada

Modele uma espada com lâmina, guarda e cabo. Use materiais diferentes e importe no Studio.

Desafio: transformar a espada em uma Tool.

🔴 Exercício 4 — Consertando erros

Teste escala, orientação e textura. Descubra qual configuração precisa ser corrigida quando o modelo chegar diferente do esperado.

🟣 Exercício 5 — Mini projeto

Crie um baú, poção, pedra, porta ou item mágico no Blender, pinte/texturize, importe e coloque no seu mapa.

🏆 Desafio final

Crie um modelo no Blender → pinte → exporte → importe → coloque no mapa → faça um script para ele interagir com o jogador.

🧠 Para memorizar

Modelar → UV → Pintar/Texturizar → Material → Exportar → Importar → Conferir → Testar.
